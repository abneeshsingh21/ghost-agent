# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 6.0.x   | ✅ Active |
| 5.0.x   | ⚠️ Critical fixes only |
| < 5.0   | ❌ Not supported |

## Responsible Disclosure

If you discover a security vulnerability within GHOST itself (e.g., a bug in the ethics engine, an unsafe deserialization, or a local privilege escalation in the web server), please report it **privately** to:

📧 **Singhabneesh250@gmail.com**

**Please include:**
- Description of the vulnerability
- Steps to reproduce
- Potential impact assessment
- Your suggested mitigation (optional but appreciated)

**Do NOT** open a public GitHub issue for security vulnerabilities.

## Scope

This security policy covers vulnerabilities **in the GHOST agent codebase itself** — not vulnerabilities that GHOST is designed to discover in third-party systems (that is its intended research function).
